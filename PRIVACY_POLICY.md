# Privacy Policy for X Following Manager

Last Updated: November 5, 2026

## 1. Introduction

X Following Manager is a Chrome extension that helps users manage their X (formerly Twitter) following list and timeline engagement through the browser interface.

We respect user privacy and aim to keep personal data under the user's control.

## 2. Information We Access

The extension may access information displayed on X pages when users activate its features, including:

- X usernames and profile information
- Posts displayed on the user's timeline
- Following list information
- User preferences and extension settings
- Text submitted for AI-assisted reply generation

This information is used only to provide the extension's requested features.

## 3. Local Data Storage

Extension settings, saved formats, API configurations, and API keys are stored locally in the user's browser using Chrome storage.

The developer does not receive users' API keys through the extension's AI request process.

## 4. AI Providers and Third-Party Services

Users can configure their own API keys and select AI providers or custom API endpoints.

When AI-assisted features are used, relevant post text and prompts may be sent to the provider selected by the user to generate replies.

API requests are sent directly from the extension's background service worker to the configured provider endpoint.

Users should review the privacy policies of their selected AI providers.

## 5. Data Sharing

We do not sell users' personal information.

The extension does not send API keys to the X website or expose them to X page scripts.

Information is shared with an AI provider only when necessary to process a user-requested AI feature.

## 6. Data Security

API keys and extension settings are stored using Chrome's local storage.

Users are responsible for protecting their browser profile and API credentials.

## 7. User Control

Users can change or delete saved API keys, settings, and configurations through the extension.

Uninstalling the extension removes its locally stored extension data according to Chrome's storage behavior.

## 8. Changes to This Policy

This Privacy Policy may be updated when the extension's features or data practices change.

Updates will be published on this page.
